# Requirement Traceability Matrix — Medical Imaging Inference Application (Layer 4)

This matrix audits `Medical_Inference_Application` (`integration/research-platform`) against the 20 Master Prompt requirement areas for Layer 4 (Local & Deployed Medical Imaging Inference Application). Every status and gap is grounded in the inspected source code, shared contracts (`packages/contracts`), frontend (`apps/frontend`), and automated test suite (`tests/`).

## Summary

- **Repository**: `Medical_Inference_Application` (branch `integration/research-platform`)
- **Shared Contracts**: `medical-imaging-platform-contracts` v1.0.0 (`packages/contracts/src/medical_imaging_contracts/models.py`)
- **Baseline Test Suite**: 33 passed, 3 skipped (optional `psycopg` / `botocore` / `streamlit` extras when absent)

## Prioritized Hardening Plan

- **P0 (Security, Integrity & Core Contracts)**:
  1. Add MLOps `/api/v1/inference/models` approved-only discovery as the default catalogue source when MLflow/local-catalogue are not configured, plus `GET /api/v1/models/approved`.
  2. Harden `verify_directory()` in `security.py` (enforce `state == "approved"`, validate JSON object manifest, 64-hex digests, manifest `model_id`/`version` consistency) and `load_export()` in `runtime.py` (eager task/framework/class_mapping checks).
  3. Align `POST /api/v1/predictions/{model_id}/{version}` response strictly with `PredictionResult v1.0` (keep `device` in audit/telemetry without polluting top-level wire schema; enrich `lineage` with governance approval metadata).
  4. Add isolated, fail-closed `INFERENCE_AUTH_MODE=dev` (requires `INFERENCE_ENVIRONMENT=development` and loopback client; forbidden in production) and cache `PyJWKClient` in OIDC mode.
- **P1 (Resilience, Timeouts & Operational Readiness)**:
  5. Add configurable inference execution timeout (`INFERENCE_TIMEOUT_SECONDS`, returning HTTP `504` and recording failed audit/telemetry), configurable cache capacity (`INFERENCE_MODEL_CACHE_SIZE`), and configurable concurrency (`INFERENCE_CONCURRENCY`).
  6. Extend `/ready` to verify both MLOps registry reachability and database reachability, and update `/api/v1/system/status` for MLOps catalogue source and cache stats.
  7. Add optional CORS middleware (`INFERENCE_CORS_ORIGINS`) for platform integration (`:8080`).
- **P2 (Observability, GUI & Comprehensive Tests)**:
  8. Extend `/api/v1/system/metrics` with `error_rate`, `p95_latency_ms`, `models` breakdown, and `cache` telemetry (preserving all existing keys).
  9. Enhance `apps/frontend/app.py` to support `INFERENCE_AUTH_MODE=dev` seamlessly and render prediction provenance (`prediction_id`, `artifact_sha256`, `disclaimer`, `lineage`).
  10. Add comprehensive unit and integration tests for all P0–P2 behaviors and verify `packages/contracts/tests/` + `tests/` pass cleanly.
